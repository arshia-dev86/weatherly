# Weatherly 🌤️

A weather dashboard built with Django REST Framework, HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Current weather conditions
- Daily weather forecast
- Responsive user interface
- Django REST API integration
- Weather data caching

## Tech Stack
- Python
- Django REST Framework
- HTML, CSS, JavaScript
- Visual Crossing Weather API

## Project Status
This project is currently under development.

The application requires a valid Visual Crossing API key and an internet connection to retrieve weather data.

## Setup
1. Install dependencies from `requirements.txt`.
2. Create a `.env` file using `.env.example`.
3. Configure your API key.
4. Run Django migrations.
5. Start the Django server.
6. Serve the frontend HTML file locally.
